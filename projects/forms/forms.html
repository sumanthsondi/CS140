1. What is JavaScript? How did it get its name?

JavaScript is a programming language used to make websites interactive. It was originally called LiveScript and was renamed JavaScript as a marketing decision. It is different from Java.

2. What are the two ways you can run JavaScript?

JavaScript can run in a web browser, such as Chrome, or on a server using an environment like Node.js.

3. What is jQuery? Is it still popular today?

jQuery is a JavaScript library that makes it easier to work with HTML elements, events, and animations. It is still used on some older websites, but modern JavaScript has replaced many of the reasons developers used it.

4. What is the most popular front-end JS library today?

React is one of the most popular front-end JavaScript libraries. It is used to build interactive user interfaces and web applications.

5. How does your code prevent the form from being submitted? Why do we need to prevent it?

My JavaScript uses preventDefault() to stop the browser's normal form submission. We prevent it so JavaScript can collect and check the form information without the page automatically reloading.
