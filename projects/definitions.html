Internet

A global network of the connected computers and hardware that alos allows data to travel all the world by cables, routers, and wireless signals

Web

A system with connected documents, pages, and media files stored on the internet that the users access using software like web browsers

How are the internet and web different?

The internet is a physical connecting devices, while the web is just one software service that works on top of that network to show pages

ASCII and Unicode

ASCII is an older coding system limited to basic english letters and numbers, whereas Unicode is a big global system designed to show almost every character and symbol from every language worlwide.

What is UTF-8

UTF-8 is the common variable width encoding format for Unicode, allowing web pages to display characters from almost any language using minimal file size

URL

A specific web address used by browser software to pinpoint and show a unique resource or page on the internet

Domain Name

A name like apple.com that stands in for a complex numbers internet address so people can easily remember website locations.

HTTP

The basic rulebook or protocol that web browsers and server computers use to send and recieve text, photos, and web content.

IP Address

A unique set of numbers or characters assigned to evey device on a network so data knows exactly where to be sent.

W3C Recommendations

The offical guidlines and tectnical standards published by the world wide web to ensure web technologies work consistently across all browsers and devices

XML,XHTML,HTML,HTML5

These are languages used to structure data and web pages XML stores and transfer data, HTML builds web page structurs, XTML5 is the modern, feature rich version of HTML used across the web today.
