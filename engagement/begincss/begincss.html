1. What is the difference between inline, embedded, and external CSS?

Inline CSS is written directly inside an HTML element using the style attribute. Embedded CSS is written inside a style tag in the HTML document. External CSS is written in a separate CSS file and connected to the HTML using a link tag.

2. Why should you only use external CSS?

External CSS keeps the HTML and CSS separate. It makes the code cleaner, easier to read, and easier to maintain. The same CSS file can also be used for multiple HTML pages.

3. What is a selector used for?

A selector tells CSS which HTML elements you want to style. For example, the p selector selects all paragraph elements.
