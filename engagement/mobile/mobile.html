1. Why do we need a viewport meta tag?

The viewport meta tag helps a website fit the width of a phone screen. It helps the page display at the correct size on different devices.

2. Which CSS rule takes priority: column or row?

If both rules have the same specificity and importance, the rule written later in the CSS takes priority when both apply.

3. How do you change CSS for a web page displayed on a phone?

We can use a media query with max-width to change the layout, text, images, and buttons for smaller screens.

4. Name two things a website changes on mobile compared to desktop.

YouTube uses a layout that fits a smaller screen on mobile. Its buttons and navigation are also arranged to make them easier to use with touch.

5. What breakpoint did you choose, and why?

I chose 700px because the sidebar and cards need more space on a large screen. Below 700px, I change the layout to make the page easier to use on a phone.
