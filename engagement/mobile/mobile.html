1. Why is the viewport meta tag important?

The viewport meta tag helps a webpage fit the screen size of a phone, tablet, or computer.

2. How can you adjust CSS for printing?

I can use the @media print rule to change how the page looks when printed. I can hide navigation and sidebars, remove background colors, and arrange cards in one column.

3. When would you adjust CSS for printing?

I would adjust CSS for printing when someone wants to print a webpage on paper. It can make the page easier to read and help save ink and paper.
