Picture Questions

1. What kind of photos are good to encode using JPEG?

JPEG is good for photographs and pictures with many colors and details. It keeps the file size smaller.

2. What kind of photos are good to encode using GIF?

GIF is good for simple pictures, animations, and images with fewer colors. It works well for small graphics.

3. What is unique about the PNG format?

PNG can have a transparent background and keeps good image quality. It is useful for logos and graphics.

4. How do you resize your photo to the size it should be displayed?

I resize the photo using photo editing software before putting it on my website.

5. Why should you resize photos using photo editing software instead of resizing it using CSS?

Photo editing software changes the actual image size and can reduce the file size. CSS only changes how large the image looks on the page.

6. What is the difference between lossy and lossless compression?

Lossy compression reduces file size by removing some image data, which can lower quality. Lossless compression keeps all the image data, so the quality stays the same.
