1. What does the action attribute do?

So the action attribute tells the browser where to send the form information after submission.

2. What does the method attribute do?

The method attribute tells the browser how to send the form information.

3. What is the difference between POST and GET?

GET sends form information in the URL. POST sends information in the request body instead of showing it in the URL.

4. How do you fill in a form control with a preset value, and how is it different from a placeholder?

Text box: Placeholder shows temporary hint text.
Textarea: Put the starting text between the opening and closing textarea tags. Placeholder shows hint text.
Checkbox: Use the checked attribute to select it by default.
Radio button: Use the checked attribute to select one by default.
