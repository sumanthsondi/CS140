Assignment Questions

1. What is AJAX?

AJAX stands for Asynchronous JavaScript and XML. It allows a webpage to send and receive information from a server without reloading the entire page.

2. Why do you put your JS code in a separate file?

Keeping JavaScript in a separate file makes the code organized, easier to read, maintain, and reuse. It also keeps HTML and JavaScript separate.

3. How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

I open Inspect and select the Console tab to look for errors. If there is an error, I can click the error message to find the file and line number where the problem happened.

4. Do your form and fields have the same IDs that your JavaScript uses? Does the Console show any errors? List your IDs, and fix any errors before you submit.

My HTML IDs match the IDs used in my JavaScript: signup-form, name, email, password, birthday, and message. I will check the Console after testing to make sure there are no JavaScript errors.
