1. What does the action attribute do?

The action attribute tells the browser where to send the form information after submission.

2. What does the method attribute do?

The method attribute tells the browser how to send the form information.

3. What is the difference between POST and GET?

GET sends form information in the URL. POST sends information in the request body instead of showing it in the URL.

4. How do you fill in a form control with a preset value, and how is it different from a placeholder?

Text box: Use the value attribute to set a starting value. Placeholder shows temporary hint text.
Textarea: Put starting text between the opening and closing textarea tags. Placeholder shows hint text.
Select box: Use the selected attribute on an option.
Checkbox: Use the checked attribute to select it by default.
Radio button: Use the checked attribute to select one by default.

5. List the HTML5 form controls. Which ones did you put in your form?

HTML5 added input types such as email, date, color, number, range, search, tel, url, time, month, week, and datetime-local. I used email, date, and color in my form.

6. What are different ways to style your form?

I can use CSS to change colors, borders, padding, margins, and font styles.

7. Why does the professor like to use Flexbox?

Flexbox makes it easier to arrange labels and input fields in rows and keep them organized.

8. What makes a good mobile form?

A good mobile form has readable text, enough space between fields, easy-to-use buttons, and a layout that fits a small screen.
