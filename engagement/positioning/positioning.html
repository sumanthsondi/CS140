Normal Flow

Normal flow is the default way that HTML elements appear on a web page. Block elements usually stack vertically, while inline elements appear beside each other within a line.

Float and Clear

Floating an image to the left allows text to wrap around its right side. This layout is useful for articles, travel stories, and news websites.

A floated figure can allow the next heading to move up beside the image when the nearby paragraph is short. The clear property makes a heading start below the floated image.

Why Clear a Float?

Clearing a float prevents a heading or section from sitting beside a floated image. It helps separate the next section from the image and its surrounding text.

Relative Positioning

Relative positioning moves an element from its original location. The space it originally occupied remains in the layout, even after the element moves.

In this example, the figure moves down and to the right. Other elements do not move into the space that the figure originally occupied.

Absolute Positioning

Absolute positioning removes an element from normal flow. It can be placed at specific coordinates within its nearest positioned ancestor.

The absolute figure does not reserve its usual space. It stays at its assigned position within its containing area rather than moving with the normal text flow.

Fixed Positioning

Fixed positioning attaches an element to the browser window. It stays in the same place on the screen while the page scrolls.

Mobile Navigation Buttons

Mobile users need navigation links that are easy to tap. Making links block-level elements allows each link to fill the available width.

Responsive web design helps a page work on different screen sizes. A flexible layout and large navigation buttons make the experience better for everyone.

Questions and Answers

1. What is normal flow in HTML?

Normal flow is the browser's default layout. Block elements stack vertically.

2. What does float do? Why do you need to clear the float?

Float moves an element to the left or right so text can wrap around it.

3. What do absolute, fixed, and relative do?

Relative moves an element from its original spot while preserving its space.
