1. When do you use a table?

I use a table when I need to organize information into rows and columns.

2. When do you not use a table?

When CSS Flexbox and Grid are better for arranging website content.

3. When do you need to do extra work for table accessibility?

I need to add a caption, proper header cells, and scope attributes so screen readers can understand the table.

4. Which question you asked AI today helped you learn the most, and why?

Learning about colspan and rowspan helped me the most because I understood how one cell can cover multiple columns or rows.

5. Did AI ever try to give you more than you asked for? What did you do?

Sometimes, yes. I asked it to explain the concepts with simple examples so I could write the code myself and practise.
