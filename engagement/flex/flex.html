1. What did I learn about Flex and CSS?

I learned that Flexbox helps arrange items in a row or a column. The parent controls how its children are positioned. I can use properties like justify-content, align-items.

2. Why do we need an accessible website?

An accessible website is easier for everyone to use, including people with disabilities. It should have clear text, useful image descriptions, and links that can be used with a keyboard.
