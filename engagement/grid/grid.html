1. What is the main difference between CSS Grid and CSS Flex?

So, CSS Grid works with rows and columns together. CSS Flex is mainly used to arrange items in one direction, either in a row or a column.

2. Who decides where a child goes on the page?

The parent decides how its children are arranged. In my three-column layout, the container uses CSS Grid to place the three columns. Each column can also be a parent and arrange its own children.
