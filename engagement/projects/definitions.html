Internet

The internet is a huge network that can connects computers all around the world.

Web

Web is a system and it has a collection of web pages that we can use with internet.

How are the internet and web different?

Actually the internet that connects devices, and the web is a service that uses the internet to show the websites.

ASCII and Unicode

ASCII is a character system for the letters, symbols, numbers. These are to support characters from other languages.

What is UTF-8?

UTF-8 is to store Unicode characters so that the computers can display text correctly.

URL

A URL is the web address used to find any website on the internet, also any specific page online.

Domain Name

A domain name is easy to remember the name of the website, example apple.com

HTTP

HTTP is a set of rules that help any browser and web server to communicate.

HTTPS

HTTPS is best for secure version of HTTP, it helps protect information to send and receive.

IP Address

IP address is a number that identifies a device or any computer on a network.

DNS

DNS is a webiste change name. like apple.com, into its IP address so the computer can find it.

W3C Recommendations

W3C recommendations are web standards that help any website work properly for long time.

XML, XHTML, HTML, HTML5

XML is used to store and organice data. Where as, XHTML is for stricter version of HTML. And HTML is used to create web pages, and the HTML5 is the newer version of HTML with more features to use.
