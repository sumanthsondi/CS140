Information

1. What are the different ways to select an item?

You can select an item by its tag name, ID, class, or its children.

2. What is the difference between an ID and a Class?

An ID is used for one specific element. A class can be used for multiple elements.

3. What is the difference between a SPAN tag and a DIV tag?

A span is used for a small part of text or content. A div is used to group larger sections of content.

4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div is a general container with no specific meaning. Header, main, and footer have specific meanings that describe the structure of a webpage.

5. What are the different ways to select a color?

You can select colors using a color name, HEX code, RGB, or HSL.
